Database Management Systems

Course Information

Course Code: CS 301

Instructor: Faculty of Engineering

Description: This course covers fundamental concepts of database systems including data modeling, relational database design, SQL, normalization, transactions, and database administration. Students will gain hands-on experience with modern database management systems.

Learning Objectives:

  • Understand database concepts and architecture
  • Design and implement relational databases
  • Master SQL for data manipulation and querying
  • Apply normalization techniques
  • Learn about transactions, concurrency, and recovery
