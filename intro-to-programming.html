Intro to Programming

Course Information

Course Code: CS 101

Instructor: Faculty of Engineering

Description: This course provides a comprehensive introduction to computer programming. Students will learn fundamental programming concepts, problem-solving techniques, and basic algorithms.

Learning Objectives:

  • Understand basic programming concepts and syntax
  • Develop problem-solving skills using computational thinking
  • Write, debug, and test simple programs
  • Learn about data types, variables, and control structures
